# Lost and found

Preserved files moved out of active configuration paths while organizing this
repo. Nothing here is loaded by the current configs. Review before restoring
or removing anything.

- `kitty/`: prior Kitty config, theme, and scratchpad backups.
- `removed-files/`: versions of `requirements.txt` and `scripts/undercover.sh`
  from the repo history; both had already been removed from the working tree.
- `sketchybar/`: the previous now-playing runtime cache value.
- `tmux/backups/`: archived tmux config and plugin checkouts, retained as
  submodules.
- `untracked-assets/`: a loose image that was not referenced by a config.
